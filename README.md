# Fyable Mecánica — demostración comercial no oficial

Sitio estático HTML, CSS y JavaScript. Abrir index.html en un navegador moderno o conectar a Cloudflare Pages (rama main, Framework preset None, build command vacío, output directory /).

## Estándar de Carpintería Los Andes
- Cabecera fija al bajar, logotipo enlazado al inicio y menú responsive.
- 11 secciones, 6 fichas de servicios y consulta, cronología histórica, 9 preguntas frecuentes.
- Galería de 6 referencias con filtro, modal, navegación por teclado y mensajes si la imagen no carga.
- Asesor interactivo de 4 situaciones que selecciona un servicio en el formulario.
- Formulario de demostración con validación local y aceptación explícita; ningún dato se guarda ni envía. Política de seguridad form-action none. 
- Teléfono flotante, enlace a Google Maps, horario publicado sujeto a confirmación, correo, footer con aviso y privacidad.
- Metadatos, favicon conceptual y noindex.

## Antes de hacerla oficial
Confirmar teléfono, correo, nave, horario, servicios, logotipo, imágenes y textos con el propietario. Los procedimientos son propuestas, no procesos verificados. No se atribuyen trabajos reales, reseñas inventadas ni especialización Saab no confirmada. Las imágenes de Unsplash y las fuentes de Google requieren Internet y no han sido verificadas visualmente; sustituir por fotos autorizadas y fuentes locales si procede. Añadir aviso legal y política de privacidad definitivos, y configurar envío seguro del formulario solo con autorización. Retirar noindex únicamente para la versión oficial.
