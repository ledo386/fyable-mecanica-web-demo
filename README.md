# Fyable Mecánica — demo no oficial
HTML, CSS y JavaScript sin compilación. Abrir index.html o conectar el repositorio a Cloudflare Pages: Framework preset None, build command vacío, output directory / (raíz).

Antes de publicar como sitio oficial: confirmar teléfono, correo, dirección, servicios, horario, logotipo, imágenes y textos con el propietario; sustituir las fotografías ilustrativas externas de Unsplash por fotos autorizadas del taller; verificar disponibilidad de imágenes y fuentes externas; añadir los avisos legales correspondientes; retirar noindex cuando exista autorización. El formulario abre el cliente de correo, no tiene backend. El proceso de trabajo es una propuesta, no una afirmación verificada. No se anuncia especialización Saab ni se inventan reseñas.
